1. EXECUTIVE SUMMARY & ARCHITECTURAL REFACTORING
--------------------------------------------------------------------------------
The engineering calculation engine for rolling bearings has been completely
centralized into a single authoritative module (/src/utils/bearingCalculations.ts).
All UI components (/src/components/BearingLifeCalculator.tsx) now delegate directly
to this pure, test-covered engine.

Key architectural improvements:
  1. Product-Specific Canonical Data: Calculation factors (e, Y, Y0, Y1, Y2, X)
     are retrieved directly from verified manufacturer catalog records in
     /src/data/products.ts. Generic fallback factors are applied only for manual
     custom inputs and are explicitly flagged.
  2. ISO 281 Exponent p Enforcement:
     - Ball Bearings (point contact): p = 3
     - Roller Bearings (line contact - cylindrical, spherical, tapered): p = 10/3
  3. Single-Row Tapered Bearing Mechanics:
     - Clear distinction between single-row radial/axial calculation and paired
       mounting arrangements (face-to-face / back-to-back).
     - Automated verification of induced axial thrust: Fa,ind = 0.5 * Fr / Y.
  4. Cylindrical & Thrust Bearing Boundary Conditions:
     - Cylindrical (NU/N type): Strict enforcement of pure radial capability (Fa = 0).
       If Fa > 0 is applied, a warning is raised and axial load is prohibited from
       distorting standard radial rating life.
     - Thrust Ball Bearings (51100 series): Pure axial capability (Fr = 0, P = Fa).
       If Fr > 0 is applied, radial forces are rejected per ISO 281 Table 6.
  5. Automated Benchmark Test Suite:
     - Built-in verification suite covering 5 canonical industrial test cases
       with <0.5% tolerance against official manufacturer calculation manuals.


2. ISO 281 & ISO 76 FORMULATION REFERENCE
--------------------------------------------------------------------------------
Dynamic Rating Life:
  L10  = (Cr / P)^p                      [million revolutions (10^6 rev)]
  L10h = (1,000,000 / (60 * n)) * L10    [operating hours]
  Lna  = a1 * L10                        [adjusted life with reliability level]
  Lnah = a1 * L10h                       [adjusted operating hours]

Reliability Factor a1 (ISO 281:2007 Table 2):
  - 90% Reliability (L10): a1 = 1.00
  - 95% Reliability (L5):  a1 = 0.64
  - 98% Reliability (L2):  a1 = 0.37
  - 99% Reliability (L1):  a1 = 0.25

Static Safety Factor s0 (ISO 76:2006):
  s0 = C0r / P0
  - Deep Groove Ball:  P0 = 0.6 * Fr + 0.5 * Fa  (if P0 < Fr, P0 = Fr)
  - Tapered Roller:    P0 = 0.5 * Fr + Y0 * Fa   (if P0 < Fr, P0 = Fr)
  - Spherical Roller:  P0 = Fr + Y0 * Fa
  - Cylindrical NU:    P0 = Fr
  - Thrust Ball 51100: P0 = Fa

4. UI / UX TRANSPARENCY & DATA LABELS
--------------------------------------------------------------------------------
The bearing life calculator UI now explicitly categorizes all parameters:
  - [Manufacturer Catalog Value]: Cr, C0r, Limiting Speed, e, Y, Y0, Y1, Y2
  - [ISO 281 / ISO 76 Calculation]: P, P0, L10, L10h, Lna, s0
  - [User Input]: Radial load (Fr), Axial load (Fa), Speed (n), Load units
  - [Product-Specific Calculation]: Indicator badge rendered whenever calculation
    factors derive directly from the bearing item's technical metadata.
  - [Automated Benchmarks Accordion]: Interactive card rendering benchmark tests
    with single-click preset loading.
