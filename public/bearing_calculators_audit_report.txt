1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
All mechanical engineering calculation tools across the Polad Charkhesh platform
were audited, corrected, and verified against international bearing standards
(ISO 281:2007 for dynamic load ratings and basic life, ISO 76:2006 for static 
safety factors, and ISO 5753-1:2009 for radial internal clearance).

Catalog values (dynamic rating Cr, static rating C0r, limiting grease/oil speed) 
are strictly consumed from verified manufacturer datasets (SKF, FAG, TIMKEN, NSK,
NACHI, KOYO). Mathematical outputs are explicitly demarcated as either:
  (a) Standard ISO 281 / ISO 76 Deterministic Calculations, or
  (b) Indicative Engineering Estimates (e.g., thermal equilibrium estimation).


2. ISO 281:2007 RATING LIFE FORMULATION & EXPONENTS
--------------------------------------------------------------------------------
Basic rating life (L10 in million revolutions and L10h in operating hours) is
calculated according to ISO 281:2007:

  L10  = (Cr / P)^p                   [10^6 revolutions]
  L10h = (10^6 / (60 * n)) * (Cr / P)^p   [Operating Hours]

Where:
  - Cr = Basic dynamic radial load rating (kN) from manufacturer catalog
  - P  = Dynamic equivalent radial load (kN)
  - n  = Rotational shaft speed (RPM)
  - p  = Life exponent based on contact kinematics:
         * Ball Bearings (point contact):     p = 3
         * Roller Bearings (line contact):    p = 10/3 (~3.3333)
           (Applied to Cylindrical, Tapered, and Spherical Roller Bearings)


3. EQUIVALENT DYNAMIC LOAD (P) & BEARING FAMILY COEFFICIENTS
--------------------------------------------------------------------------------
Dynamic equivalent load is derived using standard equations:
  P = X * Fr + Y * Fa

Coefficients X, Y, and limiting ratio e are evaluated per bearing mechanical family:

A. Deep Groove Ball Bearings (ISO 281:2007 Table 1):
   - Exact continuous piecewise linear interpolation of Fa / C0r ratio:
       Fa / C0r <= 0.014  ==>  e = 0.19,  Y = 2.30
       Fa / C0r  = 0.028  ==>  e = 0.22,  Y = 1.99
       Fa / C0r  = 0.056  ==>  e = 0.26,  Y = 1.71
       Fa / C0r  = 0.084  ==>  e = 0.28,  Y = 1.55
       Fa / C0r  = 0.110  ==>  e = 0.30,  Y = 1.45
       Fa / C0r  = 0.170  ==>  e = 0.34,  Y = 1.31
       Fa / C0r  = 0.280  ==>  e = 0.38,  Y = 1.15
       Fa / C0r  = 0.420  ==>  e = 0.42,  Y = 1.04
       Fa / C0r >= 0.560  ==>  e = 0.44,  Y = 1.00
   - Condition Fa / Fr <= e: X = 1.00, Y = 0.00 (P = Fr)
   - Condition Fa / Fr >  e: X = 0.56, Y = interpolated Y

B. Tapered Roller Bearings (Single Row, ISO 281:2007 Table 4 & ISO 355):
   - Metric series standard: e = 0.37, Y = 1.60, Y0 = 0.90
   - Fa / Fr <= e: X = 1.0, Y = 0.0  (P = Fr)
   - Fa / Fr >  e: X = 0.4, Y = 1.60 (P = 0.4*Fr + 1.60*Fa)
   - UI documents that paired sets require internal induced axial load calculation.

C. Spherical Roller Bearings (Double Row, ISO 281:2007 Table 5):
   - Standard series: e = 0.24, Y1 = 2.8, Y2 = 4.2, Y0 = 2.8
   - Fa / Fr <= e: X = 1.00, Y = 2.8 (P = Fr + 2.8*Fa)
   - Fa / Fr >  e: X = 0.67, Y = 4.2 (P = 0.67*Fr + 4.2*Fa)

D. Cylindrical Roller Bearings (ISO 281:2007 Table 2):
   - Standard non-locating (NU, N): X = 1.0, Y = 0.0 (P = Fr)
   - Explicit engineering warning is raised if Fa > 0 (flanged NJ/NUP required).

E. Thrust Ball Bearings (Single Direction, ISO 281:2007 Table 6):
   - Pure thrust (90 deg contact): X = 0.0, Y = 1.0 (P = Fa)
   - Explicit error/warning is raised if Fr > 0 (radial loads strictly forbidden).


4. STATIC SAFETY FACTOR (s0) METHODOLOGY (ISO 76:2006)
--------------------------------------------------------------------------------
Static safety factor against permanent plastic deformation of raceways:
  s0 = C0r / P0

Where equivalent static load P0 is:
  - Deep Groove Ball:  P0 = max(Fr, 0.6*Fr + 0.5*Fa)
  - Tapered Roller:    P0 = max(Fr, 0.5*Fr + 0.9*Fa)
  - Spherical Roller:  P0 = 1.0*Fr + 2.8*Fa
  - Cylindrical Roller:P0 = Fr
  - Thrust Ball:       P0 = Fa


5. RELIABILITY ADJUSTMENT FACTOR a1 (ISO 281:2007 Table 2)
--------------------------------------------------------------------------------
Adjusted fatigue life Lna = a1 * L10:
  - 90% Reliability (L10): a1 = 1.00
  - 95% Reliability (L5):  a1 = 0.64
  - 98% Reliability (L2):  a1 = 0.37
  - 99% Reliability (L1):  a1 = 0.25


6. BENCHMARK TEST CASES & RESULTS
--------------------------------------------------------------------------------
All five primary mechanical bearing families were evaluated under realistic 
industrial duty cycles:

Case 1: Deep Groove Ball Bearing (SKF / FAG 6204-2RS)
  - Input Specs:     d=20mm, D=47mm, B=14mm | Cr=13.5 kN, C0r=6.55 kN
  - Operating Duty:  Fr=2.5 kN, Fa=0.5 kN, Speed=1450 RPM
  - Fa/C0r = 0.076 ==> e = 0.274, Fa/Fr = 0.200 <= e
  - Dynamic Eq Load: P = 2.50 kN (X=1.0, Y=0.0)
  - Static Load:     P0 = 2.50 kN ==> s0 = 2.62 (Safe against indentation)
  - Rated Life L10h: 18,099 Operating Hours (26.24 Million Revolutions)

Case 2: Single-Row Tapered Roller Bearing (30206)
  - Input Specs:     d=30mm, D=62mm, B=17.25mm | Cr=43.0 kN, C0r=45.0 kN
  - Operating Duty:  Fr=8.0 kN, Fa=3.5 kN, Speed=1000 RPM
  - Fa/Fr = 0.4375 > e (0.37)
  - Dynamic Eq Load: P = 0.4*(8.0) + 1.6*(3.5) = 8.80 kN
  - Static Load:     P0 = max(8.0, 0.5*8.0 + 0.9*3.5) = 8.0 kN ==> s0 = 5.62
  - Rated Life L10h: 3,345 Operating Hours (p = 10/3, 200.7 Million Revolutions)

Case 3: Spherical Roller Bearing (22212 EK)
  - Input Specs:     d=60mm, D=110mm, B=28mm | Cr=159.0 kN, C0r=166.0 kN
  - Operating Duty:  Fr=25.0 kN, Fa=5.0 kN, Speed=750 RPM
  - Fa/Fr = 0.200 <= e (0.24)
  - Dynamic Eq Load: P = 25.0 + 2.8*(5.0) = 39.0 kN
  - Static Load:     P0 = 25.0 + 2.8*(5.0) = 39.0 kN ==> s0 = 4.25
  - Rated Life L10h: 2,395 Operating Hours (p = 10/3, 107.8 Million Revolutions)

Case 4: Cylindrical Roller Bearing (NU 208 ECP)
  - Input Specs:     d=40mm, D=80mm, B=18mm | Cr=56.0 kN, C0r=51.0 kN
  - Operating Duty:  Fr=10.0 kN, Fa=0.0 kN, Speed=1500 RPM
  - Dynamic Eq Load: P = 10.0 kN (Pure radial line contact)
  - Static Load:     P0 = 10.0 kN ==> s0 = 5.10
  - Rated Life L10h: 3,471 Operating Hours (p = 10/3, 312.4 Million Revolutions)

Case 5: Single Direction Thrust Ball Bearing (51106)
  - Input Specs:     d=30mm, D=47mm, B=11mm | Cr=20.3 kN, C0r=37.5 kN
  - Operating Duty:  Fr=0.0 kN, Fa=3.0 kN, Speed=1000 RPM
  - Dynamic Eq Load: P = 3.0 kN (Pure axial thrust)
  - Static Load:     P0 = 3.0 kN ==> s0 = 12.50
  - Rated Life L10h: 5,163 Operating Hours (p = 3, 309.8 Million Revolutions)


7. SPEED & THERMAL ESTIMATOR METHODOLOGY
--------------------------------------------------------------------------------
- Limiting speeds for grease and oil are non-negotiable manufacturer catalog limits.
- Steady-state operating temperature rise is modeled as an empirical balance 
  between frictional torque power loss (Pf = M * omega) and convective heat 
  dissipation area (W/degC).
- Results are transparently branded as "Indicative Engineering Estimates" with 
  explicit operational disclaimers.
