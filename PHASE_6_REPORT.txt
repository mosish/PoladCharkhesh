3. CORE ARCHITECTURAL PILLARS
--------------------------------------------------------------------------------
A. Cryptographic Authentication & Security
   - PBKDF2-HMAC-SHA256 Password Hashing: 100,000 iterations + 16-byte random salt.
   - HMAC-SHA256 Session Signing: Tamper-proof session tokens with TTL expiration.
   - Brute-Force Rate Limiting: 5 consecutive failed attempts trigger temporary lockout.
   - Environment Isolation: Standardized .env.example with no hardcoded credentials.

B. ISO 281 Engineering Safety Lock
   - Strict sanity validation prevents data corruption in L10 life calculators:
     * Outside Diameter (D) > Bore Diameter (d) > 0
     * Width/Thickness (B) > 0
     * Dynamic Load (Cr) > 0 and Static Load (C0r) > 0
     * Category-specific calculation factors (e, Y, Y0, Y1, Y2, f0)
     * Valid speed ratings (RPM grease/oil) and positive chamfer dimensions (rMin).

C. Reactive Single Source of Truth (dataService)
   - Real-time Observer/Subscription model.
   - Live synchronization across public storefront, search index, and admin UI.
   - Zero page reload required upon editing or archiving products.
